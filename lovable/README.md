# המרה ל-Lovable — סטודיו אבי

תיקייה זו מכילה את הפרויקט מומר ל-**React + Tailwind**, הסטאק הנייטיבי של Lovable.
הקוד כאן טרם נדחף ל-Lovable — הוא מוכן לדחיפה ומחכה לאישור.

## מה יש כאן

| קובץ | תפקיד |
|---|---|
| `StudioAviSite.tsx` | הקומפוננטה הראשית — כל האתר (9 עמודים) ב-React + Tailwind, TypeScript |
| `index.css` | טוקני העיצוב כמשתני HSL לפי מוסכמת shadcn/Lovable + `@font-face` |
| `tailwind.config.snippet.ts` | תוספות ל-`theme.extend` (צבעי מותג, אנימציות) — למיזוג, לא להחלפה |
| `public/` | נכסים: פונטים, קאברים, פוסטרים |

## השינוי הארכיטקטוני המרכזי: רצפי תמונות ← `<video>`

האתר המקורי מנגן 5 "סרטים" על גבי `<canvas>` מתוך **1,162 קבצי WebP (52MB)**,
עם `preload` מלא לפני שאפשר להתחיל.

בבדיקת הקוד המקורי התברר שהרצפים **לא מקושרים לגלילה** — הם מנוגנים לינארית
עם callback בסיום (`play(seq.s2, { onEnd })`), ואחד מהם בלולאה. זה בדיוק מה
ש-`<video>` עושה נייטיב.

**התוצאה:**

| | לפני | אחרי |
|---|---|---|
| נכסים | 1,162 קבצים | 10 קבצים |
| משקל | 52MB | 33MB (20MB דסקטופ / 13MB מובייל) |
| טעינה | preload מלא לפני הפעלה | זרימה (streaming) |
| קוד | מנוע קנבס מותאם (~200 שורות) | `<video>` + `onEnded` |

## שחזור קבצי הווידאו

קבצי ה-`.mp4` **לא נכללים ב-git** (מוחרגים ע"י `*.mp4` ב-`.gitignore`).
לשחזור מקבצי המקור (`2.mp4`–`6.mp4` בשורש הפרויקט), על macOS:

```bash
mkdir -p lovable/public/video
for n in 2 3 4 5 6; do
  avconvert --source "$n.mp4" --preset Preset1280x720 --output "lovable/public/video/s$n.mp4" --replace
  avconvert --source "$n.mp4" --preset Preset960x540  --output "lovable/public/video/s$n-sm.mp4" --replace
done
```

בדחיפה ל-Lovable יש להעלות את `public/video/` ואת שאר `public/` לפרויקט.

## הערות ליישום

- כל אפקטי הסמן (הטיה תלת-ממדית, ספוטלייט, כפתורים מגנטיים) מגודרים מאחורי
  `(hover:hover) and (pointer:fine)` ומכבדים `prefers-reduced-motion`.
- הכפתור הקולנועי (`CineButton`) נכתב בכוונה כקומפוננטה עצמאית ולא כ-shadcn `Button` —
  הווריאנטים של shadcn נלחמים בגרדיאנט/ברק/מגנט של המותג.
- `--dim` (כחול) הוא חתימת בידול התלת-מימד ומופיע רק במקומות המסומנים ככאלה.
